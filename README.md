# Banking App UI Design

A modern mobile banking application UI/UX design created as part of the Unified Mentor project.

## 📱 Project Overview

The Banking App UI Design project focuses on creating a clean, modern and intuitive mobile banking experience.

The application allows users to securely manage their finances, transfer money, manage beneficiaries, view transactions, analyze spending and manage their account settings.

The interface was designed with a mobile-first approach using Figma.

---

## 🎯 Project Objective

The main objective of this project was to design a user-friendly banking application that makes common financial tasks simple, clear and accessible.

The design focuses on:

- Simple and intuitive navigation
- Clear financial information
- Secure money transfers
- Easy transaction tracking
- Beneficiary management
- Spending analysis
- Consistent visual design
- Mobile-first user experience

## 📱 Screens Designed

### 1. Login
Secure and simple login interface for accessing the banking application.

### 2. Dashboard
Provides an overview of account balance, recent transactions and quick banking actions.

### 3. Send Money
Allows users to select a recipient, enter an amount and choose a transfer method.

### 4. Transactions
Displays transaction history with search and category filtering.

### 5. Beneficiaries
Allows users to view and manage saved recipients for faster transfers.

### 6. Analytics
Provides visual insights into spending patterns and spending categories.

### 7. Transfer Success
Confirms that a money transfer has been completed successfully and displays transaction details.

### 8. Profile & Settings
Allows users to manage personal information, security, notifications and preferences.

## 🧩 Design Process

The project followed a structured UI/UX design process:

### 1. Requirement Analysis
Understanding the required banking features and user flows.

### 2. Wireframing
Low-fidelity wireframes were created to establish the layout, information hierarchy and navigation.

### 3. Visual Design
The wireframes were transformed into a high-fidelity interface using a consistent design system.

### 4. Prototyping
Interactive connections were created in Figma to simulate the banking application experience.

### 5. Refinement
Spacing, typography, colors, components and visual consistency were refined across all screens.
